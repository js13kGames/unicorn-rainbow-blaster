Unicorn Rainbow Blaster is a compact 2D arena shooter built for js13kGames 2026, themed around Unicorns and Rainbows. You play a winged unicorn defending a dreamlike arena from waves of gloomlings — dark storm sprites that chase, drift, shoot, and charge. Your horn auto-fires rainbow bolts at the nearest threat.

Every 3 waves you pick one of three boons — Rapid Horn, Pierce, Triple Shot, Swift Hooves, Big Heart, or Lucky Clover — so each run builds differently. Every 5 waves the Gloom King boss descends, raining bullet spreads and summoning minions. Defeat it for a rainbow confetti burst and keep climbing. Survive as long as you can and beat your high score, saved between runs.

Works on desktop (WASD / arrows + mouse) and mobile (drag to move, auto-aim). The entire game — code, art, and sound-free visuals — fits in a single 7 KB HTML file with zero external assets.
